CropGuard is an AI-Based Crop Disease Prediction and Management System that uses deep learning and transfer learning with a pretrained MobileNetV2 model to identify plant diseases from leaf images across 38 healthy-plant and disease categories. The project is developed using Python, TensorFlow, Keras, NumPy, Pillow, Scikit-learn, Matplotlib, and Google Colab. It involves resizing and preprocessing leaf images, extracting image features using MobileNetV2, and classifying them into the supported categories. The system evaluates model performance using accuracy, precision, recall, F1-score, and confusion matrix analysis where available. It also provides general disease management recommendations based on the predicted class. The main project files include `CropGuard_MultiCrop_Colab.ipynb` for training, evaluation, and prediction, `crop_disease_model.keras` for the trained model, `class_names.json` for disease labels, and `requirements.txt` for the required libraries. CropGuard aims to support early disease identification and better crop management; however, its predictions are estimates, and the recommendations should be verified by a qualified agricultural expert before taking action.
